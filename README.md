# 溯微 (Suwei) v1.16.0

一款专为 SillyTavern 打造的高精度、轻量级独立悬浮式长线记忆引擎。完全独立于任何预设运行，彻底解决长楼层角色扮演中的**总结压缩丢细节、摘除饰品死灰复燃、角色上帝视角、重Roll白白消耗总结Token、以及高楼层原文 Token 爆炸**问题。

---

## ✨ 核心特性

1. **纯悬浮窗极简交互，告别繁冗侧边栏**
   - **零冗余插件设置**：不再在酒馆侧边栏扩展列表插入繁琐冗长的设置抽屉，所有配置、API 调试、记忆时间线、人物账本与轮次管理**100% 收敛至聊天界面的独立悬浮窗**。
   - 悬浮胶囊随时长按拖拽，点击即可在 **【📖 状态看板】** 与 **【⚙️ 溯微设置】** 间自由无缝切换，界面极其清爽整洁。

2. **按“一问一答轮数 (Round)”精准追踪**
   - 一问一答算一轮，真正契合对话剧情进展，绝非机械生硬的楼层。
   - 无论是多轮 L0 微摘要归档、阶段脉络向上递归合并，还是故事时间线可视化展示，全部以轮数清晰对齐。

3. **延迟定稿总结（重Roll零消耗·绝不浪费一次 API 调用）**
   - 默认采用 **“等玩家发送下一条消息时，再自动总结上一轮” (`on_next_send`)** 机制！
   - 因为最新一轮对话会直接发送完整原文给主模型，所以在你刚收到回复、还在反复重Roll（Swipe）或手动润色修改时，插件**完全不会调用总结 API**；直到你满意并发送下一条消息（代表上一条已彻底定稿），插件才会在后台静默归档。重Roll十次也只总结最终定稿的那一次！

4. **原生聊天记录替换与近期原文保留**
   - 固定替换酒馆本次生成的聊天记录区块，不再使用 Depth 插入，不改变角色卡、世界书和其他预设的位置。
   - 默认保留最近 **5 轮**完整原文；更早且已归档的部分由分层记忆接替。未归档缺口仍保留原文，多轮 L0 不会从中间截断。
   - 历史摘要、固定记忆和召回细节按来源轮次排列；状态快照放在其归档时点，后续原文中的变化优先，避免新对话中间突然插入旧日期。
   - **不按固定 Token 预算删除记忆或截断注入文本**。仍使用原有分层总结进行叙事压缩；模型/酒馆自身的上下文上限不等于插件预算。
   - 仅修改本次生成副本，聊天存档原文保持完整；旧版本由溯微隐藏的原文会恢复。可关闭“用记忆替换已归档原文”，改为保留全部原文。

5. **在场各人物状态账本 & 摘除饰品防回滚锁**
   - 按在场角色分别追踪：地点、状态与行动、衣着穿戴、随身道具。
   - **已摘除/不在身物品防回滚锁 (`removedItemsLock`)**：一旦角色摘下眼镜、耳环或脱下外套，状态账本会持续锁定“已摘下未佩戴”状态，绝不会因角色卡初始设定死灰复燃（直到剧情明确描写重新戴上才会解锁）。
   - **待办与约定追踪 (`todosAndPromises`)**：实时追踪未竟承诺与待办。

6. **分层递归金字塔记忆树 & 陈年小事按需唤醒**
   - **L0 ~ L3 递归记忆金字塔**：按步长自动向上合并阶段大纲，几百上千轮记忆常驻主模型仅需极少 Token。
   - **L0 归档粒度可配置**：可设置每 N 轮生成一条 L0；支持满 N 轮自动归档，也支持在剧情页手动选择连续未归档轮次合并，手动合并后从下一轮重新计数。
   - **按需唤醒旧事**：超出当前窗口的历史微摘要自动进入回溯池，内置零成本本地双字分词检索（亦支持硅基流动等向量 API），聊天中触及旧话题自动捞出相关细节注入上下文。

7. **v1.8.0 记忆一致性修复**
   - 总结改为后台队列，发送下一条消息时不再等待摘要 API 完成。
   - L0 总结采用原子提交：摘要、级联合并、Embedding 全部成功后才写入存档，失败重试不会产生重复 L0。
- 删除/编辑楼层会按实际影响清理或重映射摘要；无关楼层不会连带清空已经总结的条目。
   - 已摘除饰品锁由代码强制继承，只有模型明确返回 `unlockedItems` 才会解除。
   - 为 API 请求增加超时，并限制回溯池的 Embedding 数量，避免极长聊天无限膨胀。
   - API Key 不再额外镜像到 `localStorage`；非敏感设置仍保留本地备份。

8. **v1.8.1 交互与容错修复**
   - 移除模型快捷标签，只保留输入框与一键拉取模型列表。
   - 正文提取标签留空时不再显示默认说明，也不再强制内置排除标签。
   - 顶部状态提示改为短暂显示后自动收起。
   - 剧情页新增轮次范围选择，可指定区间重新总结。
   - 状态账本优先显示玩家本人，人物身份由剧情决定，不再把多人卡/大世界卡名硬套给角色。
   - 总结解析或请求失败时可自动重试，默认 2 次，并可在运行设置中调整。

9. **v1.9.0 归档可靠性、JSON 模式与身份稳定**
   - `after_reply` 模式会先补齐更早的失败缺口，再归档新轮次，避免跨轮漏记忆。
   - 独立 API 默认启用 JSON 模式；渠道不支持 `response_format` 时自动回退并记住该渠道。
   - 新增最大输出 Tokens 设置，默认 4000，降低推理模型因预算不足返回空内容的概率。
   - 429 等临时失败会读取 `Retry-After` 并等待后重试。
   - 剧情页新增“仅补缺失 / 仅筛选查看 / 重整范围及之后”三种模式。
   - 失败会持久记录，并在悬浮胶囊和剧情页显示待补轮数与“立即补总结”入口。
   - 人物账本支持 `canonicalName`、别名、在场状态和最后出场轮次；别名会合并到同一人物。
   - 旧版 `User/Char/Character` 占位人物会自动迁移清理；人物超过 60 个时优先保留玩家与最近出场者。
   - 解析失败不再把剧情原文片段写入控制台。

10. **v1.9.1 悬浮窗定位与外观设置**
   - 修复默认右上角胶囊展开时向右越界的问题；现在按左右可用空间自动换向，并在窄屏或屏幕中部向视口内回拉。
   - 设置新增独立 **【外观】** 页，可切换瓷白精修 / 书页叙事主题、选择界面字体并调节 85% ~ 130% 字号。
   - 新增“恢复默认外观”按钮；外观设置仅影响溯微悬浮窗与记忆弹窗。

11. **v1.9.2 总结进度、即时停止与完整正文**
   - 新增独立总结进度框，显示当前任务、轮次进度与进度条；完成、失败或停止后自动收起。
   - 补缺失、范围重总结、全部重总结与旧历史回溯均可即时停止；等待中的 API 请求会被中断，已完成进度会保存。
   - 白名单与黑名单均留空时，L0 总结会发送对应连续轮次的玩家输入与 AI 回复完整正文，不再隐式删除 `<details>` 内容。

12. **v1.10.1 平滑记忆层级与时间远史**
   - 最高记忆层级固定为内部 L3，不再暴露“最大递归层级数”；避免无意义的更深递归。
   - L0～L2 改为保留最近若干条，只合并最旧溢出部分，不再每逢整除点把近期层级全部清空。
   - L3 保留最早 4 条背景锚点与最近 12 条阶段摘要；超出部分滚动整合为一条按剧情内时间整理的远史摘要，不再无限累积。
   - 远史摘要禁止把楼层编号或现实发送时间当作剧情时间；没有明确日期时会使用相对时间或省略。
   - 默认向主模型发送最近 5 轮完整原文；这段窗口内不再重复注入对应 L0 摘要。
   - 记忆注入保留内部安全上限，不新增用户设置；酒馆自身的上下文 Token 统计已包含注入的记忆。
   - 悬浮窗底栏显示当前注入估算、回溯池与远史数量。

13. **v1.10.2 长线性能优化**
   - 旧历史回溯改为每 5 轮批量保存与刷新注入，不再每轮重复序列化聊天元数据。
   - 剧情时间线仅在“剧情”页可见时重建，避免隐藏页签每轮重复生成大量 DOM。
   - 编辑 L0 后的 L1～L3 重建接入统一进度框，可查看进度并安全停止。
   - 陈年记忆检索增加按条目缓存的本地分词索引，避免每轮重复扫描同一批历史摘要。

14. **v1.10.3 剧情时间线分页**
   - 剧情页改为每页 20 条，默认显示最近一页，不再一次渲染全部历史摘要。
   - 使用左右箭头在较早、较新页面间切换，并显示页码与当前页轮次范围。
   - 远史摘要归入最旧页；筛选、编辑后仍保留当前页码。

15. **v1.11.0 状态快照压缩与自动任务队列**
   - L0 状态存档改为每 20 轮保存一次完整关键帧，其余轮次只保存相对上一轮的状态差异。
   - 回滚时从最近关键帧重放差异，保留精确恢复能力。
   - 旧版逐轮完整快照会在首次加载时自动迁移为关键帧 + 差异，无需重新调用总结 API。
   - 自动归档任务不再在已有任务运行时被丢弃，而是进入串行队列，当前任务结束后自动接续。
   - 编辑 L0、回溯历史、手动补齐和剧情重总结共用同一套进度、停止与保存机制。

16. **v1.12.0 模型选择与稳定性修复**
   - 拉取模型后会生成可点击的独立模型菜单，不再依赖浏览器对 `datalist` 的点击行为。
   - 独立 API 会读取 `finish_reason`；输出达到最大 Tokens 时明确提示截断，且不会盲目重试并重复消耗额度。
   - API 超时现在同时覆盖响应头与响应体，避免渠道返回响应头后卡住读取流程。
   - 修复剧情页范围操作的设置变量缺失；范围补齐、筛选和重总结恢复可用。
   - 总结任务改为在队列获得执行机会后再申请全局进度槽，避免自动归档在并发场景中被静默跳过。
   - 切换存档会清理剧情编辑、筛选和分页状态，并中止旧存档的总结任务。
   - 待办勾选在总结期间会暂时禁用，避免手动状态被后台快照覆盖。
   - 范围重总结中途停止时会移除受影响的高层摘要，避免 L0 与 L1～L3 长期互相矛盾。
   - 原生隐藏楼层选项现在明确标注为全局轮次规则；切换后会提示重新扫描或重建。
   - 批量扫描和范围重总结改为一次生成轮次索引，避免长聊天中的重复全量扫描。
   - 删除或编辑旧楼层时会同步清理受影响的远史、待沉淀旧阶段和统计计数，避免已删除剧情从远史复活。
   - “补齐缺失”会明确提示并处理范围前的前置缺口，不再静默跨越范围。
   - 切换 API 配置档案会清空旧渠道的模型菜单。
   - 移动端点击模型框会先展开菜单，避免软键盘立即关闭列表；需要手填时选择“手动输入模型名称”。
   - 待办保存失败会恢复原来的完成状态，避免界面与存档不一致。
   - 兼容大小写、下划线、连字符以及常见渠道的 `finishReason` / `native_finish_reason` 字段。

17. **v1.13.0 看板折叠、物品清理与向量模型选择**
   - 状态看板默认折叠人物卡片，点击标题展开详情；随身道具栏也改为独立折叠，长账本更方便浏览。
   - 每件随身道具与“已摘下”记录都可单独删除，删除前会确认，并明确只修改当前状态账本、不改历史剧情。
   - 物品删除后会立即保存并刷新提示词注入；总结进行期间暂时禁止删除，避免被后台状态快照覆盖。
   - 修复模型下拉菜单在内部滚动时被全局滚动监听误收起的问题，并增强移动端触摸滚动。
   - Embedding 配置新增独立“拉取向量模型”，默认只筛选常见向量模型；可关闭筛选查看渠道返回的全部模型。

18. **v1.13.1 移除输出 Tokens 限制**
   - 独立总结 API 不再发送 `max_tokens` 参数，由渠道与模型自身决定最大输出长度。
   - 移除设置中的“最大输出 Tokens”输入项及相关配置档案字段。
   - 保留 `finish_reason=length` / `max_tokens` 截断检测；若渠道自身仍提前截断，会明确提示检查渠道默认上限或上下文窗口。

19. **v1.13.2 回滚一致性与编辑安全修复**
    - 拉取向量模型后显示原生下拉框；筛选没有命中时仍展示渠道返回结果，不再出现“拉取成功但无选项”。
    - 编辑尚未并入 L1～L3 的 L0 只保存该条摘要，不再无谓重建全部高层记忆。
    - 删除未归档楼层时保留仍能对应到原 AI 回复的摘要，并同步重映射楼层号与轮次号；只有确实覆盖被删回复的条目会失效。
    - 载入存档与删除后会按实际存活的 L0 校准处理游标，避免“摘要缺了 20/21，但待补队列从 22 开始”的错位。
    - 单轮总结、层级合并与远史摘要统一禁止主题升华、氛围渲染、心理猜测和“情感张力升腾”等结尾套话，并增加确定性清理。
   - 编辑旧楼层或切换到已有 Swipe 后，会立即恢复被溯微隐藏的原文，避免主模型短暂失去上下文。
   - `after_reply` 模式下切换已有 Swipe 会在延迟窗口后自动补总结；若紧接着开始新生成，则自动取消本次补总结。
   - 剧情总结编辑改为事务式重建：先从单轮摘要重建 L1～L3 与远史，成功后才保存；失败、停止或保存异常时保留原摘要，避免高层记忆永久丢失。
   - 编辑 L1/L2/L3 时会把修改映射回其来源摘要，再向上重建，避免只清空而不恢复。
   - 停止总结会同时作废后续排队任务，不再出现“停止后下一项继续执行”。
   - 删除随身物品、勾选待办会同步写入最近 L0 的状态快照，后续回滚不再复活手工修正前的状态。
   - 长聊天增加轮次索引缓存与单帧 UI 合并刷新，减少重复全量扫描和 DOM 重建。
   - 模型列表拉取兼容填写完整 `/chat/completions`、`/embeddings` 地址；悬浮胶囊支持键盘展开。

20. **v1.14.0 多轮 L0 与手动合并**
    - 新增“每几轮合成一条 L0”，默认 1 轮，可设置 1～50 轮。
    - 新增自动 / 手动 L0 归档模式；自动模式满指定轮数才调用一次 L0 总结，手动模式不会自动生成 L0。
    - 自动模式仍可手动提前合并：在剧情页选择“手动合 L0”，从当前最新未归档轮次开始合并任意连续范围。
    - 手动合并后处理游标推进到该 L0 的结束轮，下一段自动计数从结束轮之后重新开始。
    - 多轮 L0 使用 `起始轮-结束轮` 记录范围；删除范围内任一楼会失效整条 L0，未受影响的后续 L0 会同步重映射楼层和轮次。

21. **v1.15.0 可见记忆、固定与恢复**
    - 状态看板新增“本轮记忆注入预览”：v1.16 起显示准备替换的完整聊天记录，包含来源轮次和近期原文，支持复制；查看不调用 API。不包含角色卡、世界书或其他预设。
    - 剧情页可固定最多 12 条 L0。已合入高层的固定 L0 仍独立参与注入；v1.16 起不再受固定 Token 预算裁剪。手工重总结同一范围会保留固定标记，删除/编辑原文导致回滚时会正常失效。
    - 已归档的近期 L0 会立即显示在剧情页的“当前记忆”中。模型收到最近原文时，仍会跳过已被完整原文覆盖的普通 L0，避免重复注入。
    - 剧情页新增人物、关系、约定和事件关键词搜索，可切换“当前记忆 / 全部 L0 归档 / 仅固定记忆”。搜索只筛选已存文本，不额外调用模型推断关系。
    - 导入、清空、重总结、编辑剧情、删除物品和勾选待办前建立恢复点；随当前聊天元数据保留最近 3 个，总上限约 400 万字符。数据页可以恢复或下载所选备份，恢复前会再保存当前状态。
    - 恢复点绑定原文指纹。聊天原文增删改、切换 Swipe 或分支内容变化后禁止直接恢复；可下载 JSON 手工处理。切换聊天时各档恢复点相互隔离。

## 📦 安装与使用

1. 打开 SillyTavern，进入顶部菜单 **扩展 (Extensions)** -> **安装扩展 (Install Extension)**。
2. 输入本仓库链接 `https://github.com/longfeng257/tiandao-memory-engine` 点击安装。
3. 进入任意聊天界面，即可在右上角看到 **🌌 溯微** 悬浮胶囊：
   - 点击展开看板，切换到 **【⚙️ 溯微设置】** 标签页，填入用于总结的高性价比独立 API（如 DeepSeek-V3、Gemini-2.5-Flash、硅基流动等 OpenAI 兼容接口）。
   - 点击 **测试独立 API 连接**，成功后即可享受全自动长线记忆与状态追踪！

### 独立总结请求设置

- **请求超时**：默认 600 秒；填 `0` 表示不设超时，最多 24 小时。超时和流式格式错误不会自动重试，避免旧请求仍在渠道生成时重复计费。
- **请求模式**：可选非流式或流式。流式会边生成边读取，更适合长思维链；渠道忽略或拒绝 `stream` 时会自动回退普通 JSON。流式使用空闲超时，收到数据会重新计时。
- 以上设置会随 **API 配置档案** 一起保存，切换配置后立即生效。

> **隐私与费用提示**：启用自动总结后，当前轮次的玩家输入与 AI 回复会发送到你配置的独立总结 API。请确认该渠道的隐私政策、数据留存方式和计费规则；长线聊天的层级合并与历史回溯也会消耗额外 Token。请优先使用可信的 HTTPS 端点，HTTP 会明文传输 API Key 与剧情内容。
