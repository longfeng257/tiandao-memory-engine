# 天道·溯微记忆引擎 (Tiandao Memory Engine) v1.2.0

一款专为 SillyTavern 打造的高精度、零配置长线记忆管理插件。完全独立于任何预设运行，彻底解决长楼层角色扮演中的**总结压缩丢细节、摘除饰品死灰复燃、角色全知视角（上帝视角）、重Roll白白消耗总结Token、以及高楼层原文 Token 爆炸**问题。

---

## ✨ 五大核心特性

1. **延迟定稿总结（重Roll零消耗·绝不浪费一次 API 调用）**
   - 默认采用 **“等玩家发送下一条消息时，再自动总结上一轮” (`on_next_send`)** 机制！
   - 因为最新一轮对话本来就会直接发送完整原文给主模型，所以在你刚收到回复、还在反复重Roll（Swipe）或手动润色修改时，插件**完全不会调用总结 API**；直到你满意并发送下一条消息（代表上一条已彻底定稿），插件才会在后台静默把上一轮总结归档。重Roll十次也只总结最终定稿的那一次！

2. **自定义发送几楼原文（超出部分自动隐藏，只看插件总结）**
   - 默认开启 **【自动隐藏超出楼层原文】**，你可以自由设定 **“仅发送最近 N 楼完整原文”**（例如设为 6 楼）。
   - 每次生成时，只有最近 N 楼会发送完整正文，超出 N 楼的所有早期楼层会被插件自动设为隐藏（不再发送原文，完全由天道插件的分层记忆树 + 物理状态账本接管），让几百上千层的长篇角色扮演始终保持极低 Token 消耗与超快响应速度！
   - 随时可调大保留层数或点击 **【👁️ 恢复全部原文】** 一键无损恢复。

3. **零配置动态物理状态账本（永不因隐藏原文或压缩而丢失）**
   - 无需手动填写任何“敏感物品词表”。每轮自动识别剧情中新增、消耗、转移的道具，以及人物当前的穿着，并自动淘汰过时的一次性杂物。
   - **已摘除/不在身物品防回滚锁 (`removedItemsLock`)**：一旦角色摘下眼镜、耳环或脱下外套，状态账本会持续锁定“已摘下未佩戴”状态，哪怕隐藏了几百层前文，也绝不会因角色卡初始设定而死灰复燃（直到剧情明确描写重新戴上才会解锁）。
   - **防全知信息隔离表 (`knowledgeIsolation`)**：自动记录私密事件或独处行为的知情者边界，严防不在场角色开启上帝视角。
   - **待办与约定追踪 (`todosAndPromises`)**：每轮实时更新日程与双方约定。

4. **分层递归金字塔记忆树（$O(\log N)$ 控制 Token）**
   - **L0（单轮微摘要）**：每轮定稿后调用高性价比独立 API 总结本轮细节（默认保留最近 5 条）。
   - **L1（小阶段摘要）**：当 L0 满 5 条（1~5、6~10...）时，自动合并为 1 条 L1。
   - **L2（大阶段摘要）**：当 L1 满 5 条（即代表 1~25 层楼）时，自动合并为 1 条 L2。
   - 支持自由调节合并步长、最大层级、注入位置与注入角色（System / User / Assistant），几百上千层楼常驻记忆仅需约 1000 Token。

5. **陈年小事按需唤醒 & 存量历史断点回溯**
   - **按需捞取小事**：当 L0 微摘要被合并为 L1 后，原件自动转入**历史小事回溯池 (`archivePool`)**。每次对话前根据当前多轮语境，自动从几百层前的微摘要池中捞出最相关的 Top-K 条陈年细节注入上下文（内置零成本本地双字分词检索，亦支持硅基流动 `BAAI/bge-m3` 等外部向量 API）。
   - **存量历史断点回溯**：中途在几百楼开启插件时，点击 **【一键扫描旧历史构建记忆树】** 即可自动分批扫描旧楼层，每完成一批次实时自动保存（支持随时暂停与断点续传）。

## 📦 安装方法（通过 GitHub URL 导入酒馆）

1. 将本文件夹 (`tiandao-memory-engine`) 下的所有文件上传到你的 GitHub 新建公开仓库（例如 `https://github.com/你的用户名/tiandao-memory-engine`）。
2. 打开 SillyTavern，进入顶部菜单 **扩展 (Extensions)** -> **安装扩展 (Install Extension)**。
3. 输入你的 GitHub 仓库链接，点击安装即可。
4. 在扩展列表中展开 **🌌 天道·溯微记忆引擎**，填入用于总结的高性价比独立 API（如 `DeepSeek-V3`、`Gemini-2.5-Flash` 或硅基流动等 OpenAI 兼容接口），点击 **测试独立 API 连接** 即可开始使用！
